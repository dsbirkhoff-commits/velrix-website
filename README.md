# VELRIX — website

AI-receptionist voor autogarages. Intelligent systems for business.

## Ontwikkelen

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployen op Vercel

1. Importeer deze repo in [Vercel](https://vercel.com/new).
2. Framework preset: **Vite** (wordt automatisch gedetecteerd).
3. Build command: `npm run build` — Output directory: `dist`.
4. Geen environment variables nodig.

Routes:
- `/` — marketingsite
- `/demo` — interactieve VELRIX Reception-demo
